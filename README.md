## 🚀 Overview

**SabiLabs** is a modern corporate web platform and intelligent business process automation hub. Built on Next.js 15 and Tailwind CSS, it delivers high-performance server-side rendering, dynamic interactive client dashboards, and seamless webhook integration for enterprise automation workflows.

---

## ✨ Key Capabilities

- **High-Performance Web Architecture**: Built with the Next.js 15 App Router, leveraging Server Components for ultra-fast First Contentful Paint (FCP).
- **Enterprise Design System**: Tailored with Tailwind CSS for high-contrast accessibility and responsive cross-device layouts.
- **Automation Pipeline Hub**: Direct integration with backend webhook receivers and background agent orchestration loops.
- **Type-Safe Full-Stack Interfaces**: Comprehensive TypeScript typing across component trees, props, and API response schemas.

---

## 🛠️ Technology Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (React 19 Server Components)
- **Language**: [TypeScript 5](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Package Manager**: `npm` / `pnpm`

## 💻 Getting Started

### Prerequisites
- Node.js 20+ installed
- npm or pnpm

### Local Development
```bash
# Clone the repository
git clone https://github.com/NET0HUNTER/sabilabs-web.git
cd sabilabs-web

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
